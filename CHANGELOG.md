# Changelog

## [0.1.0] — 2026-02-10

### Added
- Initial release
- Audio conversion: MP3, WAV, OGG, FLAC, AAC, M4A, WMA, OPUS
- Video conversion: MP4, MKV, AVI, MOV, WEBM, FLV, WMV, TS
- Image conversion: PNG, JPEG, BMP, GIF, WEBP, TIFF, AVIF, ICO
- Document conversion: PDF, DOCX, XLSX, PPTX, ODT, ODS, ODP, EPUB
- Parallel processing with rayon
- Interactive folder browser
- Auto-dependency installation
- Persistent configuration
